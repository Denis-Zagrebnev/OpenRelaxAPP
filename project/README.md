# OpenRelaxAPP

VK-бот для поиска мероприятий через публичный API [KudaGo](https://kudago.com/public-api/). Бот помогает выбрать город, дату и категорию, а затем показывает подходящие события прямо в диалоге сообщества ВКонтакте.

## Возможности

- выбор города из списка;
- выбор даты на ближайшие семь дней;
- поиск по категории или по собственному текстовому запросу;
- просмотр краткой информации, подробностей и программы мероприятия;
- поиск похожих событий и переход между страницами результатов;
- управление через кнопки в сообщениях сообщества VK.

## Технологии

- Python 3.12;
- VKBottle 4.10+;
- KudaGo API;
- Requests;
- python-dotenv.

## Установка

Клонируйте репозиторий и перейдите в каталог приложения:

```powershell
git clone https://github.com/Denis-Zagrebnev/OpenRelaxAPP.git
cd OpenRelaxAPP\project
```

Создайте виртуальное окружение:

```powershell
python -m venv venv
```

Активируйте его в PowerShell:

```powershell
venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

## Настройка VK

1. Включите сообщения сообщества.
2. Откройте `Управление → Сообщения → Настройки для бота` и включите **Возможности ботов**.
3. В разделе `Управление → Работа с API` включите Long Poll API и событие **Входящее сообщение**.
4. Создайте ключ доступа сообщества с правом на сообщения.

Никогда не публикуйте ключ доступа и не добавляйте файл `.env` в Git.

## Переменные окружения

Создайте файл `.env` в каталоге `project`:

```dotenv
VK_TOKEN=ключ_доступа_сообщества
DEFAULT_CITY=msk
```

`VK_TOKEN` обязателен. `DEFAULT_CITY` можно не указывать — по умолчанию используется Москва (`msk`). Дополнительно приложение поддерживает переменные `REQUEST_TIMEOUT`, `DEFAULT_PAGE_SIZE`, `MAX_PAGE_SIZE` и `DEFAULT_LANG`.

## Запуск

Из каталога `project` выполните:

```powershell
venv\Scripts\python.exe main.py
```

Если виртуальное окружение уже активировано, можно использовать:

```powershell
python main.py
```

После запуска отправьте сообществу одну из команд: `привет`, `начать` или `меню`.

> Если приветствие пришло, но кнопки не видны, нажмите значок клавиатуры рядом с полем ввода сообщения — панель кнопок VK может быть свёрнута.

## Как пользоваться ботом

1. Откройте диалог с сообществом и отправьте `привет`.
2. При необходимости выберите город и дату.
3. Выберите категорию или укажите свой вариант.
4. Запустите поиск и откройте подробности интересующего события.

Если город или дата не выбраны, бот использует город по умолчанию и текущую дату.

## Структура проекта

```text
project/
├── main.py              # точка входа
├── vk_bot.py            # клавиатуры и обработчики VKBottle
├── event_service.py     # бизнес-логика поиска мероприятий
├── kudago_api.py        # клиент KudaGo API
├── models.py            # модели данных
├── config.py            # загрузка настроек из окружения
├── utils.py             # вспомогательные функции
├── requirements.txt     # зависимости Python
└── .env                 # локальные секреты, не добавлять в Git
```

